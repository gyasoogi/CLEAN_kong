# KONG'S BATH TIME — 콩이 목욕 대작전!

React + TypeScript + Vite로 만든 브라우저 플레이형 미니게임입니다. 캐릭터는 CSS 일러스트로 구성되어 별도 이미지 에셋 없이 실행됩니다.

## 실행 방법

```bash
npm install
npm run dev
```

개발 서버가 표시하는 주소(기본 `http://localhost:5173`)로 접속하면 됩니다.

## 프로덕션 빌드

```bash
npm run build
npm run preview
```

빌드 결과물은 `dist/`에 생성됩니다.

## 조작 방법

1. **콩이 잡기:** 강아지를 누른 상태로 포인터를 강아지 가까이에 유지합니다. 게이지가 100%가 되면 성공합니다.
2. **물 끼얹기:** 움직이는 포인터가 파란 목표 구간에 들어왔을 때 버튼 또는 게이지를 누릅니다. PERFECT / GOOD 판정 점수가 적심 게이지에 누적됩니다.
3. **샴푸 복복:** 큰 버튼을 빠르게 연타합니다. 일정 시간 입력이 없으면 거품 게이지가 조금씩 감소합니다. 스페이스/Enter 키도 사용할 수 있습니다.
4. **드라이:** 방향키 또는 A/D로 노란 마커를 움직이는 파란 목표 구간 안에 유지합니다. 모바일에서는 좌우 버튼을 길게 누릅니다.

## 기록 및 공유

- 타이머는 타이틀 화면에서 `시작하기`를 누르는 순간 시작하며 스테이지 전환 중에도 계속 흐릅니다.
- 타이틀 화면의 `랭킹 보기`에서는 이 브라우저에 저장된 상위 20개 기록을 확인할 수 있습니다.
- 랭킹 등록은 사용자의 동의를 받은 후 닉네임과 기록을 `localStorage`에 저장합니다. 같은 브라우저/기기에서만 보이는 로컬 랭킹입니다.
- X 공유는 기록과 순위를 포함한 게시글 작성 화면을 엽니다.
- 결과 PNG는 브라우저 Canvas API로 생성하므로 외부 이미지 라이브러리가 필요하지 않습니다.

## 온라인 랭킹 확장 지점

현재 랭킹 데이터 접근은 `readLeaderboard()`와 `saveLeaderboard()`에 분리되어 있습니다. 향후 API 연동 시 이 두 함수를 서버 조회/등록 함수로 교체하고, 등록 응답에서 전역 순위를 반환하도록 확장하면 됩니다.
